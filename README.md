## Kurulum

[Releases](../../releases/latest) sayfasından `tulpar-tools-<sürüm>-windows-x64-setup.exe`
dosyasını indirip çalıştırın. Kurulum yönetici izni istemez; Tulpar Tools yalnız sizin
kullanıcı hesabınıza kurulur.

## Neler yapar

- **Tek yerden kurulum:** Tulpar programlarını tek tıkla kurar ve başlatır.
- **Otomatik güncelleme:** Yeni sürümleri kendisi denetler, indirir ve doğrular; kendi
  güncellemelerini de sessizce kurar.
- **Arka planda çalışır:** Pencereyi kapattığınızda saatin yanındaki sistem tepsisinde
  çalışmaya devam eder ve Windows açılışında sessizce başlar. İkisi de Ayarlar'dan kapatılabilir.

## Sistem gereksinimleri

- Windows 10 veya Windows 11, 64 bit
